## [0.2.1] · 阶段 1 补充 —— 本地模式（2026-10-24）

### 新增

- **本地模式**：未配置 Supabase 时应用完全可用——注册/登录/配对/日记/照片/纪念日全流程在本机浏览器内完成，零配置直接运行。
  - 文字数据存 localStorage（`leafstory:*` 键），照片 Blob 存 IndexedDB（`leafstory-media` 库），不上传任何服务器。
  - `src/services/local/localBackend.ts` 与云端服务**同一套函数签名**，页面代码零改动；五个 service 在入口按 `isSupabaseConfigured` 分流。
  - 可见性与配对规则**镜像云端 RLS/RPC**：伴侣仅见「双方可见且已发布」、草稿/私密仅作者、仅作者可改删；邀请码 24 小时、一次性、空间上限 2 人、一人一空间。全部由 10 个新增单测覆盖（共 47 个测试）。
  - 诚实的模式提示：顶部横幅与设置页明确「数据只保存在这台设备、清除浏览器数据会一并删除」；配置 `.env` 并重启即可切换云端同步。
- 找回密码在本地模式给出诚实提示（不支持邮件找回），不假装发送。
- 密码哈希优先 SHA-256（Web Crypto），环境不支持时降级非安全哈希并注明非安全边界。

### 说明

- 本地模式与云端模式**不互通**（各自独立存储）；未来如需迁移本地数据到云端，可在阶段 6 数据导出中实现。

## [0.2.0] · 阶段 1 —— 双人账户、恋爱日记与纪念日（MVP）（2026-10-24）

### 新增

- **认证**：Supabase Auth 邮箱密码注册/登录/退出/找回密码；注册即建档案（数据库触发器）；登录态全局上下文；未登录访问受保护页面自动跳转登录并记住来路。
- **双人配对**：创建二人空间生成 12 位邀请码（只存 SHA-256 哈希、24 小时有效、一次性）；凭码加入由 SECURITY DEFINER RPC 在事务内完成「验码→锁空间→人数上限→入组→作废」，并发下无法加入第三人；未配对/待配对（可重新生成邀请码）/已配对三态 UI。
- **日记**：新建/编辑/删除/详情；标题、正文、发生日期（本地日历日）、六种心情（对应六种叶子颜色，用户手选）、分类标签、双方可见/仅自己可见、草稿/发布；关键词搜索 + 心情/作者筛选 + 按月时间轴 + 分页加载；照片多张上传（≤9 张、单张 ≤10MB、Canvas 压缩、私有桶 + 短期签名 URL + 灯箱大图）；仅作者可改删。
- **纪念日**：五类纪念日 CRUD、每年重复/一次性、按本地日历日的「已经过/还有 N 天」倒计时（含 2/29 闰年处理）、相识/在一起/第一次约会金叶标记、足迹页下一个纪念日卡片。
- **森林首页**：回忆之树接入真实「双方可见已发布」日记——心情着色的可点击叶片（聚合上限 24 片）、叶片总数、最近回忆列表、下一个纪念日。
- **设置页**：邮箱展示、昵称/时区编辑保存、二人空间状态、退出登录（二次确认）。
- **数据库迁移 00002**：couple_invitations、diary_entries、diary_media、anniversaries 四表 + 全表 RLS；配对三 RPC + 档案触发器 + updated_at 触发器；Storage 私有桶路径级策略（couple/{couple_id}/… 仅空间成员可读写）。
- **测试**：新增纪念日倒计时/闰年、心情唯一性、表单校验等单测（共 37 个测试）。

### 安全

- 日记可见性完全由 RLS 决定：作者全量可见自己的（含草稿/私密）；伴侣仅可见「双方可见且已发布」；媒体行跟随所属日记。
- 邀请码库中只存哈希；明文码仅创建时展示一次；重新生成会使旧码作废。
- 所有 SECURITY DEFINER 函数固定 `search_path=''` 并显式检查 `auth.uid()`。

### 已知限制（留待后续）

- 迁移尚未在真实 Supabase 项目上执行（本机无项目）；需按 README 在 Dashboard 依次执行 00001、00002。
- A/B/C 三账号隐私实测需真实环境（docs/SECURITY.md 附手工步骤）。
- 服务端 MIME 深度嗅探未实现（当前为客户端校验 + 扩展名约束 + RLS 权限），可在阶段 7 收尾加固。
- 深色模式、E2E 测试仍按计划留待后续阶段。
