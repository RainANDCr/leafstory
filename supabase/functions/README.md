# supabase/functions —— Edge Functions

需要服务端私密逻辑（不能信任客户端）的功能放在这里，例如（按阶段规划）：

- 阶段 1：邀请码校验与入组（事务内检查：一次性、未过期、空间未满 2 人）
- 阶段 3：时光邮局「到期解锁」读取（服务端校验解锁时间与收件权限）
- 阶段 5：AI 故事编辑师中转（BYOK Key 不落库、供应商白名单、防 SSRF）

约定：

- 所有函数必须校验调用者 JWT 与双人空间归属，不信任任何客户端参数。
- SECURITY DEFINER 类的数据库函数必须固定 `search_path` 并显式检查 `auth.uid()`。
- 绝不在日志中输出用户内容、信件正文或任何 API Key。
